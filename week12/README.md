# 12주차 AI 협업 프로그래밍

## 1. 프로그램 소개
pandas를 활용하여 성적 CSV 데이터를 정제하고 필터링, 그룹화, 통계 분석을 수행하는 프로그램이다.

## 2. 제작 목적
잘못된 데이터가 분석 결과에 영향을 주지 않도록 정제하고, AI가 작성한 코드의 정확성을 직접 검증하기 위해 제작하였다.

## 3. 데이터
- scores_2026.csv: 원본 성적 데이터 114행 5열, UTF-8
- scores_2026_cp949.csv: 인코딩 오류 실험용 데이터
- mini.csv: 손계산 검증용 데이터 10행
- 데이터 열: 학번, 이름, 반, 과목, 점수

## 4. 데이터 정제 규칙
- 점수가 비어 있는 행 6개 제거
- 중복 행 4개 제거
- 반과 과목 이름의 앞뒤 공백 제거
- 0~100 범위를 벗어난 점수 4개 제거
- 최종 데이터 100행

## 5. 실행 방법
- py -m pip install pandas pytest
- py analysis.py

## 6. 분석 결과
- 수학 데이터: 38행
- 1반 90점 이상: 11행
- 1반 평균: 78.24점
- 2반 평균: 71.44점
- 전체 점수 합계: 7484점
- 1반 수학 평균: 60.0점

## 7. 테스트 방법 및 결과
실행 명령어: py -m pytest test_analysis.py -q

- 정상 테스트: 4개 통과
- 공백 제거 생략 실험: 1개 실패, 3개 통과
- 점수 범위 변경 실험: 1개 실패, 3개 통과
- 정상 코드 복구: 4개 통과 (0.50초)

## 8. 파일 구성
- analysis.py: 데이터 정제 및 분석 코드
- test_analysis.py: 분석 결과 검증 코드
- CSV 파일 3개: 실습용 데이터
- prompts.txt: AI 협업 프롬프트
- README.md: 프로그램 설명

## 9. AI 활용 및 소감
AI를 활용하여 데이터 정제, 필터링, 그룹화, 통계 분석 코드를 작성하였다. 원본 데이터와 정제된 데이터를 혼동하는 오류를 직접 발견하고 수정하였다. 손계산과 pytest를 통해 분석 결과를 검증하였다. AI가 작성한 코드라도 직접 실행하고 결과를 확인하는 과정이 중요하다는 것을 알게 되었다.
